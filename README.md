# 星耀竞技场 · Star Arena

一个**零依赖、单文件**的 3v3 抢星竞技小游戏，用原生 JavaScript + Canvas2D 实现，双击即可在浏览器里玩。手机、平板、电脑自适应，支持触屏多点操作与键鼠操作，内置 AI 队友与对手。

> 本作品为**原创独立小游戏**，游戏名、角色名、技能名与美术表现均为原创，与任何第三方游戏或作品无关。

## 玩法

- 地图中央的**星能矿井**会不断喷出星星，击败携带星星的敌人也会掉落星星。
- 把星星拾取并**携带**在身上，**率先集齐 10 颗并守住 15 秒**即获胜；若时间（150 秒）耗尽，则携带星星多的一方获胜。
- 被击败会掉落身上所有星星——优势方要保护携带者，劣势方要抢回节奏。
- 草丛可隐身，适合偷袭或撤退。

## 运行

直接用浏览器打开 `star-arena.html` 即可，无需安装、无需构建、无需联网。

```bash
# 方式一：直接打开
open star-arena.html          # macOS
# xdg-open star-arena.html    # Linux
# start star-arena.html       # Windows

# 方式二：本地静态服务器（可选）
python3 -m http.server 8000   # 然后访问 http://localhost:8000/star-arena.html
```

## 操作

- **电脑**：`WASD` 移动 · 鼠标瞄准 · 左键 / `J` 攻击 · `K` 技能 · 空格 必杀技 · `Esc` 暂停 · `M` 静音
- **手机 / 平板**：左半屏按住拖动 = 虚拟摇杆移动；右侧按钮攻击 / 技能 / 必杀技；按钮支持拖动手动瞄准，支持多点触控（左手走位 + 右手释放）。

## 快速开局参数（URL Query）

| 参数 | 说明 |
| --- | --- |
| `?autostart=1` | 跳过选人直接进入对局 |
| `?hero=0..9` | 预选英雄序号（0=芒果 … 9=烈烈） |
| `?diff=0/1/2` | 难度：休闲 / 标准 / 极限 |
| `?mute=1` | 静音启动 |

例如：`star-arena.html?autostart=1&hero=9&diff=2&mute=1`

## 技术

- 纯原生 **HTML + CSS + JavaScript**，单文件，无任何外部依赖或资源。
- **Canvas2D** 程序化绘制角色、特效与地图；**WebAudio** 实时合成音效。
- 对手 AI 采用状态机 + A\* 寻路 + 视线（LOS）判断；地图固定、坐标确定性，便于测试与复现。
- 自适应布局：竖屏保持纵向可滚动，横屏紧凑排布；平板/手机/桌面统一体验。
- 通过 `localStorage` 保存英雄/难度/音效/战绩偏好。
